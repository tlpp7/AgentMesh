# Q02–Q05 — WCAG 2.2 AA accessibility verification

- [ ] Q02: Header/main/navigation landmarks and skip link reachable by Tab
- [ ] Q02: Every input has a programmatic name and each error announces its state
- [ ] Q03: Graph agents can be selected via keyboard-accessible alternative list
- [ ] Q03: Selected node and status have screen-reader text equivalents
- [ ] Q04: Visible focus and reduced-motion support
- [ ] Q04: Text contrast 4.5:1 (normal), 3:1 (large), and non-text contrast 3:1 where applicable
- [ ] Q04: Verify 200%/400% zoom and narrow viewports without loss
- [ ] Q05: Automated axe-core scan of main user journeys
- [ ] Q05: Manual NVDA/VoiceOver and keyboard-only review
- [ ] Q05: Record criterion-level evidence and remediations

Automated passes alone are not WCAG certification. This checklist tracks evidence to collect. Use WAI-ARIA 1.2 only when native HTML is insufficient.
